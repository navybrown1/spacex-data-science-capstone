# spacex-data-science-capstone

## Project Overview
This capstone project analyzes SpaceX launch data to predict landing success and understand factors affecting mission outcomes.

## Completed Components

### Data Collection
- **spacex_wiki_scrape.ipynb** - ✅ Completed and functional
  - Successfully scrapes Falcon 9 launch data from Wikipedia
  - Extracts launch information including dates, sites, payloads, and outcomes
  - Data cleaned and prepared for analysis
  - Status: Fully operational and ready for capstone presentation

### Analysis Notebooks
- **spacex_api_wiki.ipynb** - SpaceX API data collection
- **spacex_eda_dataviz.ipynb** - Exploratory data analysis and visualization
- **spacex_sql_lab.ipynb** - SQL-based data analysis

### Machine Learning
- **lab1_folium_complete.py** - Interactive map visualization
- **lab2_ml_complete.py** - Predictive modeling for landing success
